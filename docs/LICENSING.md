# Licensing Model

Squish uses an open-core model.

## Open Source Core

- Package: `squish-memory`
- License: MIT (`LICENSE`)
- Includes local mode, MCP server integration, installer/verification scripts, and self-hosted workflows.

## Commercial Offering

Remote managed control-plane features are commercial and provided as a hosted service.

Commercial scope includes:

- Managed remote control plane
- Multi-tenant operations and admin workflows
- SLA-backed support and enterprise operations
- Managed auth and hosted reliability features

## Versioning and rights

- Published historical npm versions remain under the terms they were released with.
- New versions can evolve licensing and packaging strategy for commercial services.
