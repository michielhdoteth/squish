# Load to Context

Add a memory to your working set for tracking.

## Usage
```
/load-to-context <memoryId>
```

## What it does
Adds a memory to your current working set. This tracks what memories you're actively using in this session.

**Note**: Claude manages its own context and tokens intelligently. This tool just helps you track WHAT you've loaded for visibility.

## Example
```
/load-to-context mem_abc123
```

## Finding Memory IDs
Use `/search` or `/recall` to find memory IDs.
