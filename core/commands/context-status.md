# Context Status

View working set status and core memory usage.

## Usage
```
/context-status
```

## What it shows
- **Core Memory**: Size usage and percentage
- **Working Set**: How many memories you've loaded
- **Available**: Total memories and observations in the database

**Note**: Claude manages its own context and token limits intelligently. This shows what memories you've loaded into your working set for organization.

## Example
```
/context-status
```

Provides a comprehensive view of your memory system state.
